# Indian Railway Station Codes (JSON Dataset)


[![Dataset](https://img.shields.io/badge/Data-JSON-blue.svg)](#)


A clean, structured, and up-to-date JSON dataset of Indian Railways (IRCTC / Indian Railways) station names and their corresponding railway station codes. 

Perfect for developers building travel apps, railway booking bots, autocomplete inputs, search engines, and data analytics tools.
